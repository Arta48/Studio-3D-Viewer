**Studio 3D Viewer** — это профессиональный, легковесный и математически строгий инструмент для инспекции 3D-моделей. Проект создавался с упором на чистую архитектуру компьютерной графики, отказ от "костылей" и бескомпромиссное следование индустриальным стандартам (Khronos glTF 2.0 и Alias|Wavefront).

Движок написан на **C++17** с использованием аппаратно-ускоренного **OpenGL** (через interleaved VBO/VAO пайплайн). Он включает в себя честную физическую модель освещения (PBR), работу в линейном цветовом пространстве и автономную структуру "Zero-Asset".

---

## ✨ Ключевые возможности

*   **Аппаратное ускорение (GPU Core):** Никаких циклов отрисовки на CPU. Геометрия упаковывается в единый 48-байтный буфер и отправляется в видеопамять для нативного индексированного рендера через `glDrawElements` (EBO).
*   **Физически корректный рендеринг (PBR):** 
    *   Честный расчет шероховатости (Roughness) и металличности (Metallic).
    *   Закон сохранения энергии (поглощение диффузного света при зеркальном отражении).
    *   Аппроксимация Френеля по Шлику и отражения студийного софтбокса.
*   **Правильная оптика:** Перевод текстур в линейное цветовое пространство (Linear) с последующей аппаратной гамма-коррекцией (2.2) при выводе на монитор. Никаких выгоревших цветов или проваленных теней.
*   **Двойная система камер:**
    *   `Орбитальная камера` — стандартный осмотр предмета со всех сторон.
    *   `Режим полёта (WASD)` — свободная FPS-камера с захватом курсора мыши. Позволяет плавно залетать внутрь салона автомобилей или исследовать масштабные сцены.
*   **Профессиональные инструменты инспекции:**
    *   `Clay Mode (Глина)` — временно скрывает текстуры и прозрачные элементы (стекла/тени), заливая модель матовой студийной глиной (`MatCap`) для оценки топологии.
    *   `Smooth / Flat Shading` — мгновенное переключение плоских и гладких нормалей за счет экранных производных (`dFdx`/`dFdy`) без перестроения меша.
    *   `Фильтрация текстур` — автоматическое применение `GL_NEAREST` для пиксель-арта (Minecraft/Blockbench) и `GL_LINEAR_MIPMAP_LINEAR` для HD-моделей.
*   **Асинхронная многопоточность:** Чтение геометрии с диска и распаковка текстур вынесены в пулы фоновых потоков (`QtConcurrent` + `QThread`), благодаря чему интерфейс не зависает ни на миллисекунду.
*   **Автономный интерфейс (Zero-Asset UI):** Тулбар и рабочая область не зависят от внешних картинок — все функциональные иконки процедурно отрисовываются вектором через `QPainterPath`, что гарантирует беспроблемную статическую сборку в один переносимый исполняемый файл.
*   **Нативность и локализация:** Высокопроизводительное приложение на C++ и Qt6. Интерфейс автоматически переключается между русским и английским языком в зависимости от настроек вашей ОС.

## 🚀 Поддерживаемые форматы и стандарты

1.  **glTF 2.0 / GLB (Современный стандарт)**
    *   Полный парсинг иерархии графа сцены и матриц трансформации.
    *   Полный стек PBR-материалов: извлечение `baseColorFactor`, `roughnessFactor`, `metallicFactor`, карт нормалей, излучения (Emissive), окклюзии (AO) и стекла (`KHR_materials_transmission`).
    *   Чтение JSON-спецификации `samplers` для автоматического применения правильного сглаживания текстур.
2.  **Wavefront OBJ + MTL (Классический стандарт)**
    *   Поддержка N-угольников (триангуляция методом веера).
    *   Автогенерация сглаженных нормалей через прямое векторное накопление по граням с учётом их площади.
    *   Поддержка классической конвертации блеска `Ns`, а также современных PBR-расширений формата MTL (`Pr`, `Pm`).

## 🛠️ Сборка и установка

### 🐧 Сборка под Linux (Arch Linux / Manjaro)

1. Установите необходимые зависимости (компилятор, CMake, Qt6, Create-DMG):
   ```bash
   sudo pacman -S base-devel cmake qt6-base mesa
   ```
2. Склонируйте репозиторий и запустите скрипт сборки:
   ```bash
   git clone https://github.com/Arta48/Studio-3D-Viewer.git
   cd Studio3DViewer
   ```
3. Скомпилируйте и запустите:
```bash
sh compile.sh
./build/Studio3DViewer
```

### 🪟 Сборка под Windows

Проект включает скрипт для полностью автоматизированной сборки независимого `.exe` файла, который не требует предварительной настройки окружения.

1. Запустите файл `compile.bat` (двойным кликом или через консоль).
2. Скрипт всё сделает за вас:
   * Скачает и установит среду **MSYS2** (в `C:\msys64`).
   * Скачает компилятор GCC, CMake и статическую версию Qt6 со всеми зависимостями.
   * Сконфигурирует и скомпилирует проект.
3. Готовый файл `Studio3DViewer.exe` будет лежать в директории `build-windows/`.

*💡 Примечание: Для полной очистки системы от среды сборки после окончания компиляции достаточно просто удалить папку `C:\msys64`.*

### 🐧 Кросс-компиляция для Windows (из-под Linux)

Проект поддерживает сборку статического `.exe` файла для Windows напрямую из Linux через кросс-компиляцию MinGW.

1. Установите MinGW и добавьте репозитории `ownstuff`:
   ```bash
   sudo pacman -S mingw-w64-gcc
   
   if ! grep -q "ownstuff" /etc/pacman.conf; then
       echo -e "
   [ownstuff]
   SigLevel = Optional TrustAll
   Server = https://ftp.f3l.de/~martchus/\$repo/os/\$arch
   Server = https://martchus.dyn.f3l.de/repo/arch/\$repo/os/\$arch" | sudo tee -a /etc/pacman.conf > /dev/null
   fi
   
   sudo pacman-key --keyserver keyserver.ubuntu.com --recv-keys B9E36A7275FC61B464B67907E06FE8F53CDC6A4C
   sudo pacman-key --finger B9E36A7275FC61B464B67907E06FE8F53CDC6A4C
   sudo pacman-key --lsign-key B9E36A7275FC61B464B67907E06FE8F53CDC6A4C
   
   sudo pacman -Syy
   sudo pacman -S mingw-w64-cmake mingw-w64-qt6-base-static
   ```
2. Запустите скрипт сборки для Windows:
   ```bash
   sh compile_windows.sh
   ```
